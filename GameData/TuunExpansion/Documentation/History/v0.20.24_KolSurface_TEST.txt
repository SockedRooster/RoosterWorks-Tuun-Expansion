TuunExpansion v0.20.24 - Kol Surface TEST

Based on v0.20.23. Skab, resources and previous surface/scatter passes
are preserved. This is Kol's first dedicated heightmap/material test.

Terrain: stronger Highlands relief (~-1575/+1407 m relative to baseline)
and gentler Frozen Plains variation (~-230/+246 m). Features span roughly
40/20/10 km. Basin and Polar height pixels remain byte-for-byte unchanged.
2048x1024 uint16 heightfield retained; no additional saturated maximum
pixels. Original one maximum pixel remains. Deformity 8300 and offset
-3500 are unchanged. New Kol_v02024.bin cache path requests scaled-terrain
regeneration. Global color/biome maps, orbit and science are unchanged.

Ground material: reuses the approved Arktane icy regolith and matching
normal/neutral data as Kol-specific texture files. All four material tiers
use them; bump scale 1.20 -> 0.65. Displacement stays zero. This replaces
the miniature global-map detail texture and its repeated crater/polar bands.
No new image generation was needed for Kol; original Arktane prompt is
included in the package. Other material settings and Kol scatter unchanged.

Install: replace GameData/TuunExpansion with this ZIP's folder and restart
KSP, keeping dependencies. Allow Kol cache regeneration. Reposition any
previously landed Kol craft on the new terrain before testing. Inspect
Highlands, Plains, Basins and Polar Terrain in daylight for height variation,
ground texture repetition, seams and local/distant terrain alignment.

Numeric heightfield, asset/config and ZIP checks passed. In-game visual
and collision testing remains pending. Previous v0.20.23 resource coverage
is retained; real scan results and external mod interactions are untested.
Lukas tree flicker remains deferred. See the separate handoff bundle for
current status and instructions to continue this project in another chat.
