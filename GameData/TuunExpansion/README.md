# TuunExpansion v1.0.4

**Stable release · Maintainer-tested in KSP**

TuunExpansion extends **Promised Worlds** with 16 additional planets and moons: Hurr, Verda, Rem, Aven, Flot, Tavool, Tom, Lukas, Raga, Vez, Dot, Arktane, Skab, Kol, Bub, and Ixia. Promised Worlds provides Tuun, Puf, and the parent system.

## Dependencies

- **Required:** Promised Worlds, Kopernicus, ModuleManager
- **Detailed terrain and scatters:** Parallax Continued and Parallax Stock Scatter Textures
- **Recommended visuals:** Scatterer and EVE
- **Optional resources:** Community Resource Pack (CRP)

Third-party dependencies and their assets are not bundled. Choose compatible versions.

## Installation

Close KSP and back up saves. Install the dependencies, replace the old `GameData/TuunExpansion` folder, then extract the new release's `GameData` folder into the KSP directory. Avoid nested or duplicate GameData folders.

## Changes and limitations

v1.0.4 repairs the orbital longitude seams on Ixia, Skab, Arktane, and Lukas with 4096×2048 color maps. Heightmaps, biomes, terrain-shaped meshes, science, and resources retain the accepted v1.0.0 baseline.

Lukas tree flicker remains unresolved. Some dry below-zero basins are intentional; older landed vessels may need repositioning. Dense scatters and high-resolution textures can increase GPU workload.

The maintainer has confirmed successful in-game testing. Packaging-script validation alone does not verify third-party dependencies.
