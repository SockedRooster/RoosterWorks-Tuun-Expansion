Tuun Expansion v0.11.1

Hurr terrain patch restructured around the supplied Promised Worlds Tuun architecture.

- Standard Kopernicus VertexHeightMap retained for Hurr's base geography.
- OPM/CTTP material experiment removed.
- Stock PQS material restored as the safe base layer.
- Added Promised Worlds-style Parallax PQS subdivision patch.
- Added Promised Worlds-style Subdivide fallback patch.
- Added native ParallaxTerrain entry for Hurr.
- Hurr temporarily uses Promised Worlds Puf's proven Parallax material maps.
- Hurr's own height/color/biome/atmosphere/science data remain unchanged.

This build intentionally does NOT add ParallaxScaledProperties yet. The first goal
is stable loading plus proper landed surface detail without touching scaled-space.
