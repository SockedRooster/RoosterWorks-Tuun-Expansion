TuunExpansion v0.20.20 - Vez Highlands and Scatter TEST

Based on v0.20.19, whose ground texture the user approved.
All regolith/material textures and material settings are unchanged.

Scatter: VezRocks spawnChance 0.10 -> 0.40; populationMultiplier 2 -> 4.
Combined intended density multiplier is 8 times before terrain filtering,
user scatter settings and runtime limits. Render limits 180/500/1200 ->
720/2000/4800. Meshes, sizes, seed, tint, slope filters, collision setting,
300 m draw distance and 75/150 m LOD transitions unchanged. More objects
can cost more rendering/collision time; check performance in the same sites.

Heightfield: original 2048x1024 16-bit map had 6.06% of all pixels and
27.01% of Highlands pixels saturated at 65535, producing capped plateaus.
Elevation <=6048 m is byte-for-byte unchanged. A smooth adjustment starts
above 6048 m and reaches full strength at 7392 m: 10% upper-height
compression plus up to +/-504 m of deterministic smooth spherical detail.
Former 8400 m plateaus now center around 7560 m with rolling relief.
No output pixels saturate at maximum. Highest sampled terrain is ~8026 m.
Upper terrain can be lowered by up to ~1262 m. Deformity remains 8400 m;
offset remains zero. Longitude-periodic, pole-consistent detail adds no
new noise seam; existing global heightmap seam characteristics are retained.

Only Vez_Height.png, Vez scatter and Vez's cache path changed in gameplay
files. Vez.cfg now uses Cache/Vez_v02020.bin so Kopernicus regenerates the
scaled terrain mesh. The old cache remains packaged but is not referenced.
Rings, color/biome maps, orbit, science, all other bodies and Dot are intact.

Install: replace GameData/TuunExpansion with this ZIP's TuunExpansion
folder and restart KSP. Keep dependencies. Allow Vez's cache regeneration
to finish. Reposition your test craft onto the new highland surface before
testing: previously saved landed positions may sit above the lowered ground.
Compare highlands at several sites, then check midlands/basins, rock
coverage, terrain alignment and performance. Test distant and close views.

Height data and package checks passed. Actual terrain/collision behavior,
scatter density and performance require in-game testing. Lukas remains
deferred. Vez is not marked complete until this adjustment is accepted.
