TuunExpansion v0.20.23 - Skab Terrain + Resource Coverage TEST

Based on v0.20.22. Prior completed ground materials and Vez/Arktane
terrain/scatter are unchanged.

Skab:
- New square 1024x1024 charcoal regolith with pale mineral fragments,
  matching wrapped normal detail and neutral auxiliary material maps.
  All four terrain material tiers use it; bump scale 1.22 -> 0.65.
  Displacement remains zero. Global color/biome maps and impact markings
  are preserved; the small tiled texture no longer repeats the planet map.
- New smooth spherical landform relief on Highlands and Plains. Actual
  Highlands changes -1422/+1346 m; Plains -470/+435 m. Features span
  roughly 19/10/5 km, with feathered biome boundaries.
- Basins and Polar height pixels are byte-for-byte unchanged. Original
  2048x1024 16-bit height data dimensions retained, no max-height clipping.
  Deformity 6800 and offset -2900 unchanged. New Skab_v02023.bin cache
  path requests scaled-terrain regeneration. Orbit, science unchanged.
- Skab scatter unchanged. This request covers its heightmap and material.
- Texture generated with the built-in image generator; exact prompt
  included in Skab_Regolith_PROMPT.txt; shader data computed locally.

Planetary resource audit:
- Eight worlds lacked explicit expansion distributions: Bub, Lukas,
  Dot, Vez, Arktane, Skab, Kol and Ixia. Added 24 body-specific Ore,
  Water and MetallicOre definitions. Previous default resources could
  still apply; lack of explicit entries did not mean resources were absent.
- Water is strongest on icy worlds/Lukas, scarce on rocky dry moons;
  ore/metals favor rock-rich bodies. These are gameplay design ranges.
- Verda's two one-line nodes expanded to canonical multiline format,
  retaining their numeric values. Tavool's surface distributions set to
  zero because it has no landable surface. Other old balances retained.
- 48 unique definitions checked across 16 configured bodies. Stock Ore
  ungated; Water/MetallicOre require CommunityResourcePack. No new
  resource types, harvesting parts, atmospheric/oceanic extraction or
  complete Kerbalism/MKS/Rational Resources integration is introduced.
- See RESOURCE_AUDIT_v0.20.23.md for all design ranges and runtime limits.

Install: replace GameData/TuunExpansion with this ZIP's folder and fully
restart KSP. Retain dependencies; allow Skab cache regeneration. Reposition
existing Skab landed craft onto the edited terrain before testing.
Inspect Skab highlands/plains and retained basins/poles in daylight,
including close terrain and distant alignment. For resource verification,
use a disposable test save with your intended mods and perform orbital
and surface scans. No main-save resource/scan state has been changed.
Installed mods/settings/save seed may change the actual deposits.

Heightfield, resource structure/gates/coverage, asset paths and ZIP checks
passed. In-game rendering, terrain collisions and resource availability
still require testing. Lukas flicker remains deferred.
