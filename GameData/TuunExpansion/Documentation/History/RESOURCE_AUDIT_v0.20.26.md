# Bub resource addendum

Existing 48 resource overrides preserved; three new Bub crust overrides bring the total to 51 unique body/resource/type combinations.

| Resource | Presence chance | Minimum | Maximum |
|---|---:|---:|---:|
| Minerals | 100 | 0.8 | 4.0 |
| RareMetals | 45 | 0.02 | 0.35 |
| Substrate | 60 | 0.15 | 1.5 |

All three require CommunityResourcePack, use ResourceType 0, Variance 45, Dispersal 4. Values are game-balance choices, not measured composition or guaranteed local concentrations. Existing Bub Ore/Water/MetallicOre distributions are unchanged. Validate with surface/orbital scans in a disposable save; existing save resource state may affect observations.

Resource names verified against [CRP CommonResources.cfg](https://github.com/UmbraSpaceIndustries/CommunityResourcePack/blob/main/FOR_RELEASE/GameData/CommunityResourcePack/CommonResources.cfg).
