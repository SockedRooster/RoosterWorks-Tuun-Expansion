TuunExpansion v0.20.19 - Vez Surface Pass TEST

Built from v0.20.18. Dot's finished surface and all Lukas settings preserved.
Vez ground now uses a square 1024x1024 blue-gray regolith albedo rather
than a miniature global planetary map. All four ground tiers use this
tile with matching wrapped-derivative normal detail and neutral auxiliary
maps. Bump scale 1.18 -> 0.65. Displacement remains disabled; existing
tiling 0.048 and other terrain material settings remain unchanged.

Existing VezRocks scatter: spawnChance 0.055 -> 0.10 (~1.82 times),
maximum scale 0.45 -> 0.65, tint 0.72/0.68/0.64 -> 0.58/0.64/0.72.
Minimum scale 0.10, population multiplier 2, seed 759, draw range 300 m,
LOD transitions 75/150 m, slope filtering and render limits unchanged.
Uses the same stock slab meshes/textures already referenced by Vez.

Global terrain shape, color/height/biome maps, rings, orbit and science
are unchanged. Original detail maps are retained but no longer referenced.

Albedo generated using the built-in image generator; exact prompt in
Vez_Regolith_PROMPT.txt. Shader data maps computed locally. Tile and ZIP
checks are not a substitute for in-game rendering/collision validation.

Install: replace GameData/TuunExpansion with this ZIP's TuunExpansion
folder, retaining dependencies. Fully restart KSP.
Test Vez's midlands, basins, highlands and poles in daylight. Check the
straight patch boundaries shown in the previous screenshot, repeated
motifs, brightness, rock placement/density and performance. Approach and
recede across 75/150/300 m. Let teleport easing finish before assessing
landing or collision. If seams persist, investigate runtime terrain UV
and material integration separately. Lukas tree flicker stays deferred.
